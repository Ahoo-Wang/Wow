## Highlights

- **`wow-webflux` is refactored from first principles** (#4086). Each query kind has one factory keyed by its route's handler key, the three state load handlers are one `LoadAggregateHandlerFunction` driven by `StateLoadRoute`, every state, snapshot and compensate route names its aggregate through the request identity, and tracing resolves its range on one path. Main code shrinks from 6,647 to 5,709 lines and from 94 to 75 files.
- **Only public entry APIs wait for v10** (#4085, [compatibility debt](https://github.com/Ahoo-Wang/Wow/blob/main/docs/compat-debt.md)). The REST API, `CommandGateway` and the query gateways, the `wow-api` programming model and DSLs, configuration, storage and wire formats and the npm packages stay compatible until v10. Internal implementation changes in a minor release without a deprecation cycle, so 9.7.0 removes the deprecated internal helpers early (#4087, #4089).
- **The operations routes are documented** (#4085, [data access](https://wow.ahoo.me/guide/data-access#operations-routes)). State tracing, the event stream load, snapshot regenerate, event compensate and the state event resend have no owner path segment and are not isolated by owner; the guide says how to protect them.

> [!IMPORTANT]
> **REST routes, route ids, handler keys, the OpenAPI document, configuration and wire formats are those of 9.6.2**, so 9.6.x and 9.7.0 nodes can run side by side. Applications that build their routes through the starter need no source change; recompile against 9.7.0. Code that builds `wow-webflux` routes itself, or calls one of the removed helpers, follows the [migration guide](https://wow.ahoo.me/guide/migration#upgrading-from-9-6-to-9-7-0).

## Breaking

**Policy.** Following the compatibility scope of #4085, internal implementation changes cleanly, without binary-only shims or deprecation cycles. Every v9 REST, storage and wire surface is unchanged.

### TypeScript

No API changes.

### Kotlin / JVM

#### `wow-webflux`

- **Query factories keyed by handler key** (#4086). Removed: `Count`/`List`/`Paged`/`CursorQuery`/`Single` `…SnapshotHandlerFunctionFactory`, their `…SnapshotStateHandlerFunctionFactory` variants, `Count`/`List`/`Paged`/`CursorQueryEventStreamHandlerFunctionFactory`, `SnapshotSchemaHandlerFunctionFactory` and `EventStreamSchemaHandlerFunctionFactory`. The `*QueryHandlerFunctionFactory` classes are final. **Affects:** code that builds query routes itself. **Migrate:** use `CountQueryHandlerFunctionFactory`, `ListQueryHandlerFunctionFactory`, … with `BuiltInHttpRouteHandlerKeys.Snapshot.*` or `Event.*`. For a `*_STATE` route also pass `rewriteResult = { it.toStateDocument() }`, or `toStateDocumentPagedList()` for a paged route and `toStateDocumentCursorPage()` for a cursor route. Use `QuerySchemaHandlerFunctionFactory(handlerKey, …)` for the schema routes.
- **One state load handler** (#4086). Removed: `AbstractLoadAggregateHandlerFunction`, `LoadVersionedAggregateHandlerFunction(Factory)` and `LoadTimeBasedAggregateHandlerFunction(Factory)`. **Migrate:** `LoadAggregateHandlerFunction(Factory)` with `route = StateLoadRoute.VERSIONED` or `StateLoadRoute.TIME_BASED`.
- **Constructors and fields** (#4086). `DefaultCommandMessageExtractor` and `RouterFunctionBuilder` lose their secondary constructors; the same arguments work through the primary constructor. `AggregateTracingHandlerFunction`, `CommandHandlerFunction` and `CommandFacadeHandlerFunction` no longer expose their collaborators as fields. `EMPTY_OK` (`me.ahoo.wow.webflux.wait`) is private. **Migrate:** recompile.
- **Request identity readers removed** (#4087): `ServerRequest.getTenantId`, `getTenantIdOrDefault`, `getOwnerId`, `getSpaceId` (both overloads) and `getAggregateId` (all three overloads). **Affects:** custom handlers that read identity from the request. **Migrate:** `identity(aggregateMetadata)` or `identity(aggregateRouteMetadata)` (`me.ahoo.wow.webflux.route.identity`): `tenantId()` (`?: TenantId.DEFAULT_TENANT_ID` for the old `getTenantIdOrDefault`), `ownerId()`, `aggregateId()`, `spaceId()`, `requestId()`. The `AggregateRoute.Owner` overloads have no replacement: the aggregate's own owner policy applies.
- **Error helpers removed** (#4087): `Throwable.toResponseEntity()` and `ErrorInfo.toServerResponse()`. **Migrate:** `WebFluxErrorStrategy.toServerResponse`, or the `RequestExceptionHandler` bean.

#### `wow-core`, `wow-tck`

- **`MessageBus.receive(subscription)` removed** (#4089), with `DefaultMethodContract.COMPAT_ADAPTERS` (`wow-tck`), which existed only to exempt it. **Migrate:** `receiver(subscription).openedMessages()`.
- **Static `RecoverableExceptionRegistrar.register`, `unregister` and `getRecoverableType` removed** (#4089). **Migrate:** the same methods of `RecoverableExceptionRegistry.DEFAULT`, or a `RecoverableExceptionProvider`.

#### `wow-openapi`

- **`CommandComponent.Header`, `CommonComponent.Header` and the `me.ahoo.wow.openapi.BatchResult` typealias removed** (#4089). **Migrate:** `me.ahoo.wow.rest.CommandHeaders`, `WowHeaders` and `BatchResult` (`wow-rest-contract`). The header values on the wire are unchanged.

#### `wow-spring-boot-starter`

- **`WebFluxAutoConfiguration.queryRouteModule(...)` takes an `ObjectProvider<ScopeContributor>`** (#4090), after `queryRequestScope`; the starter's query routes and point-read admission compose the caller scope the same way. The starter's own route modules build the keyed factories of #4086. **Affects:** code that calls this `@Bean` method directly. **Migrate:** pass `beanFactory.getBeanProvider(ScopeContributor::class.java)`.

## Behaviour changes

- **Tracing errors before the response starts** (#4086). A tracing request with a `limit` whose read of the stream's tail fails now answers with the error's own status. Before, an event-stream request answered `200` and then sent an error event. Under point-read admission this was already the behaviour. **Act:** nothing.

## Deprecations

None new. Removed early, before v10, because they are internal implementation: the `wow-webflux` request identity readers and error helpers (#4087), `MessageBus.receive`, the static `RecoverableExceptionRegistrar` calls and the `wow-openapi` header and `BatchResult` aliases (#4089).

## TypeScript packages

Install or upgrade with a `~9.7` range: a minor release may break (see [version ranges](https://wow.ahoo.me/guide/typescript/compatibility#version-ranges)). Every package in `PUBLISHED` (`.github/scripts/publish-npm.mjs`) ships together at `9.7.0`; the packages peer on each other with `~`, so upgrade them together. The fetcher peer ranges are unchanged.
