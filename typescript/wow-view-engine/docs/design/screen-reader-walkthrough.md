# 真人读屏走查清单（首发前）

给不是可访问性专家的维护者：照着做，一个人、约 30 分钟，用 VoiceOver 把视图引擎的核心任务走一遍，并把听到的话记下来交回。

- **为什么要做**：2026-09-25 的走查（#3424）只用了 Chromium 算出的无障碍树、Playwright 的 ARIA 快照和播报区的文字，说明了「应该念什么」，说明不了读屏软件**实际**怎么念、念几遍、会不会被打断。见文档站「视图引擎的可访问性」的「评估方法」，与 [todo.md](todo.md)「可访问性」第一条。
- **本页里「应听到」的话**是从代码里的措辞目录（`src/ui/messages/zh-CN.ts`）、`aria-label` 与播报区（`aria-live`、`role=status`、`role=alert`）逐句抄来的；带「大意是」的是按规则拼出来的句子，具体的字以现场为准。VoiceOver 还会在名字后面加上它自己的词（「按钮」「复选框」「已勾选」「对话框」「组」「无效数据」等），不用逐字比这些。
- **已知缺口不算新失败**：[todo.md](todo.md)「可访问性」里已记的几条（仪表盘改筛选不出声、调列宽念查询不念宽度、记录表没有名字、指标卡走势小图没有摘要句、视图的面没有 `lang`）照实记下「听到了什么」即可，严重程度按那条已有的记，不要重复开问题。

时间分配：准备 5 分钟，十个任务约 20 分钟，记录与交回 5 分钟。

## 一、准备（5 分钟）

### 1. 打开和关掉 VoiceOver

- **开／关**：Command+F5。键盘顶排是媒体键的 MacBook 用 Fn+Command+F5，或按住 Command 连按三下触控 ID。第一次打开会弹欢迎窗，选「使用 VoiceOver」。
- **VO 键**：下文写作 **VO**，就是同时按住 Control+Option（在 VoiceOver 实用工具里也可以改成大写锁定键）。
- **最常用的几组键**：

| 想做什么                                   | 按键                                                  |
| ------------------------------------------ | ----------------------------------------------------- |
| 读下一项／上一项                           | VO+→ ／ VO+←                                          |
| 按下当前项（等于点击）                     | VO+空格                                               |
| 进入一组（表格、工具栏、区域）／退出这一组 | VO+Shift+↓ ／ VO+Shift+↑                              |
| 转子：按地标、标题、表单控件、表格列出     | VO+U，然后 ←／→ 换类别、↑／↓ 选、Enter 跳过去、Esc 关 |
| 下一个标题／下一个表单控件／下一张表格     | VO+Command+H ／ VO+Command+J ／ VO+Command+T          |
| 从这里往下连读                             | VO+A                                                  |
| 马上闭嘴                                   | Control                                               |
| 再念一遍刚才那句／把刚才那句拷到剪贴板     | VO+Z ／ VO+Shift+C                                    |

- **把听到的话看得见**：打开 VoiceOver 实用工具（VO+F8）→「视觉」→ 勾选「显示字幕面板」。屏幕下方会逐句显示念出的字，记录时照抄它，比凭耳朵可靠；VO+Shift+C 也能把最后一句直接贴进记录表。
- **中文要能念出来**：VoiceOver 实用工具 →「语音」里确认装了中文语音（如「婷婷」），并勾选「检测语言」。Storybook 的页面把整页的 `lang` 写成英文、视图引擎的面自己不写 `lang`（已知缺口 3.1.2），所以关掉「检测语言」时中文可能被当成英文念成乱码——那是这一条缺口，记一次即可。
- **语速**：VoiceOver 实用工具 →「语音」→「速率」，调到听得清的程度；走查不比快。

### 2. 浏览器：Safari（推荐）

- **用 Safari 走 VoiceOver**：两者同一家、同一套无障碍接口，是 Mac 读屏用户实际的组合。Chrome 配 VoiceOver 也能用，但偶有漏念和重念，出了问题分不清是谁的，这次不用它。
- **Safari 的 Tab 设置**：Safari →「设置」→「高级」→ 勾选「按 Tab 键高亮显示网页上的每个项目」。不勾时 Tab 只停在文本框上，按钮和链接被跳过（#3424 记过，这是平台默认，不是缺陷）。
- **两种走法都要用**：Tab／Shift+Tab 走的是键盘焦点，VO+→／VO+← 走的是 VoiceOver 的光标。任务里写「Tab 到」就按 Tab；写「读到」就用 VO+→ 或转子。

**可选：Windows 上的 NVDA + Firefox**（有时间或有 Windows 机器时再做，同一份清单）：Control+Alt+N 启动；NVDA 键是 Insert；NVDA+空格在浏览模式与焦点模式之间切换；浏览模式下 H 标题、D 地标、T 表格、F 表单控件，NVDA+F7 列出元素，Control+Alt+方向键在表格里走；「工具 → 语音查看器」把念出的字逐句显示出来，记录时照抄；NVDA+Q 退出。

### 3. 打开哪里

每个任务给的是故事的**单独页面**（`iframe.html`），没有 Storybook 自己的侧栏和工具栏——少一层读屏要穿过的界面，听到的都是视图引擎和示例宿主的。

- **发布的站点**（不用装任何东西）：`https://wow.ahoo.me/storybook/iframe.html?viewMode=story&id=<故事 id>`，下文每个任务都给了完整链接。它随文档站部署，可能比 `main` 晚几次合并。
- **本机**（要验证刚合并的修复时）：仓库根目录 `pnpm install`，再 `pnpm --filter wow-storybook storybook`，打开 `http://localhost:6006/iframe.html?viewMode=story&id=<故事 id>`。链接里的域名与路径前缀换掉即可，故事 id 相同。
- 想看带侧栏的完整 Storybook：`https://wow.ahoo.me/storybook/?path=/story/<故事 id>`。

### 4. 主题

- **默认就是 porcelain**（Storybook 的缺省预设），不用设。
- **contrast 走一次**：任务 6 在链接末尾加 `&globals=fvePreset:contrast` 再做一遍（下文给了链接）。读屏念的话应当与 porcelain 一字不差；要看的是焦点环清楚、图上钉了花纹。

### 5. 减弱动态效果与缩放（各看一次）

- **减弱动态效果，整个走查都开着**：系统设置 →「辅助功能」→「显示」→ 打开「减弱动态效果」，刷新页面。应当看到：弹层、菜单、抽屉直接出现，不缩放、不滑入；图表不做生长动画；**转圈和骨架屏仍在动**（它们说「还在进行」，按设计不停）。走完记得关回去。
- **缩放，在任务 1 末尾做**：Safari 里 Command+= 放到 200%（想多看一步就到 400%），Command+0 复原。应当看到：整页不出现横向滚动条（表格与图在自己的框里横向滚动是允许的）；Tab 到的控件焦点环完整、没被别的东西盖住；文字没有被截掉。

## 二、任务（约 20 分钟）

每个任务：打开链接 → 按步骤按键 → 对照「应听到」→ 把实际听到的记进第三节的表。「失败」一栏说的是什么情况要记为不通过。

### 任务 1　打开记录视图并排序（2 分钟）

[订单工作台](https://wow.ahoo.me/storybook/iframe.html?viewMode=story&id=view-engine-业务场景-订单工作台--order-workbench-scene)（故事 id `view-engine-业务场景-订单工作台--order-workbench-scene`）

它默认打开「发货超时」，这张视图每 30 秒自动刷新一次，每次都会念「正在查询」「共 11 条记录」——那是对的，但会打断你，所以先换到「全部订单」。

1. 页面载入：**应听到**「正在打开视图」，随后「共 11 条记录」。
2. VO+U → 地标 → 选「视图」（导航），VO+→ 读到「全部订单」，VO+空格。**应听到**「正在打开视图」，稍后「共 N 条记录」（N 是几万）。焦点仍在列表上。
3. VO+U → 地标：应有一个以视图名「全部订单」命名的主区域（`main` 或同名 `region`）、名为「筛选」的区域（展开后）和名为「分页」的导航。
4. Tab 到表头（整行表头只占一个 Tab 站），←／→ 在列间走，停在「实付」。**应听到**「按实付升序排序，按钮」，停一下后是描述「按住 Shift 追加排序」。
5. Enter。**应听到**「正在查询」，然后「共 N 条记录」；焦点仍在这颗按钮上，它的名字变成「按实付降序排序」，VoiceOver 会带上「升序」一类的排序状态。
6. → 到「订单状态」，Shift+Enter 追加第二个排序。**应听到**查询两句；两颗表头按钮的名字里多出「第 1 个排序条件，共 2 个」「第 2 个排序条件，共 2 个」。
7. （缩放检查）按第一节第 5 步放到 200% 看一眼，再复原。

**失败**：排序后什么也不念，或念的条数和屏幕上不同；按钮名字说的与按下去的效果不符；焦点跳出表头；在表头里 Tab 一下就跑到下一列（应是 ←／→）。

### 任务 2　筛选：加条件、应用、清空（2 分钟）

同一页，停在「全部订单」。

1. Tab 到视图标题栏的「筛选」按钮，Enter。筛选区展开，是名为「筛选」的区域。
2. Tab 到「添加」，Enter。**应听到**一个名为「选择字段」的对话框，焦点在搜索框「搜索字段」上。输入「发货」，↓ 或 Tab 到复选框「发货仓」，空格勾上。Esc（或按「完成」）关掉，**焦点应回到「添加」**。
3. 新条件排在「添加」之前：Shift+Tab 回去。条件是一组「发货仓 条件」，里面依次是「发货仓 操作符」「发货仓 值」「发货仓 条件取反」「移除 发货仓」。在「发货仓 值」里选一个仓（↓ 打开，↑／↓ 选，Enter 定）。条件上应能读到「尚未应用」。
4. Tab 到「应用」，Enter。**应听到**「正在查询」「共 N 条记录」（N 变小了）。结果上方的已应用条应读出「正在显示：全部订单」和这条条件。
5. 回到筛选区，按「清空」。**焦点应落在「应用」上**（#3424 修过：以前掉到页面开头），Enter，**应听到**「正在查询」「共 N 条记录」（回到几万）。
6. 再加一条随便什么条件、不应用，按「放弃筛选修改」：焦点同样落在「应用」上。

**失败**：任何一步之后焦点掉到页面开头（下一次 Tab 从页首重来）；条件里的控件只念「弹出式按钮」而不带字段名；应用后没有结果播报。

### 任务 3　翻页、勾选行、批量操作（2 分钟）

同一页，「全部订单」，无条件。

1. VO+U → 地标 →「分页」导航。读一遍：「上一页」（第一页时变灰）、「下一页」、页码（「第 1 / N 页」一类）、「跳到第…页」、「每页」「20 条」、「共 N 条记录」。
2. 在「下一页」上 Enter。**应听到**「正在查询」「共 N 条记录」，焦点留在「下一页」。再按「上一页」回到第一页：这一步让「上一页」变灰，**焦点应移到「下一页」**，不掉到页面开头（#3424 修过）。
3. Tab 进表格的勾选框（每行一个 Tab 站）。**应听到**「选择 〈订单号〉，复选框」，停一下后是描述「按住 Shift 勾选，从上一次勾选的那条到这一条之间的记录一并选中或取消。」空格勾上；再勾两行（可以试一次 Shift+空格连选）。
4. 结果工具栏左端出现计数：**应听到**（或读到）「已选 3 条」。
5. Tab 到「结果工具栏」（整条工具栏一个 Tab 站），←／→ 走到「催发货 3 单」，Enter。**应听到**大意是「催发货 · 正在执行 1/3」，结束后「催发货 · 3 项已完成」；「全部订单」里多数单已经发出，更常见的是「催发货 · 1 项完成，2 项失败 · 这张单已经发出，不用催（2 项） · 未完成的仍选中」。这一行后面有「知道了」按钮。
6. 行上的单条命令叫「催 〈订单号〉 发货」，按一下，结局报在同一行里。

**失败**：执行中或执行完没有任何播报（屏幕上有那一行字、耳朵里没有）；勾选数不念、也读不到；按「催发货」后焦点掉到页面开头。

### 任务 4　记录详情：打开、关闭、第二层的「返回」（3 分钟）

先在任务 1 的订单工作台里：

1. Tab 到数据行（整页行一个 Tab 站，↑／↓ 在行之间走）。行上的描述是「按 Enter 或空格打开这条记录，方向键在记录间移动。」
2. Enter。**应听到**一个对话框（侧边抽屉），焦点在标题上，标题就是这条的订单号，旁边的说明是「记录详情」。VO+Command+H 逐个读各节的标题（按定义的字段分组，最后是「其他」）。右上角的按钮叫「关闭」。
3. Esc。抽屉关上，**焦点回到刚才那一行**（念这一行的内容），不落在行里的勾选框上，也不掉到页面开头。

再开[第二层的场景](https://wow.ahoo.me/storybook/iframe.html?viewMode=story&id=view-engine-组件状态-记录工作台-记录详情--nested-embed-detail)（`view-engine-组件状态-记录工作台-记录详情--nested-embed-detail`），它一打开就是 SO-1003 的详情：

4. VO+Command+H 读节标题：「处理」在最前，后面是字段分组，「同仓订单」在后面。「同仓订单」里嵌着一张表。
5. 进那张表，Tab 到它的行，Enter 打开其中一单。**应听到**第二层对话框：头部第一个控件是按钮「返回 SO-1003」，后面的说明是「同仓订单」，再下面标题是这一单的订单号。第二层没有「关闭」按钮，只有「返回」。
6. Esc：**只关第二层**，焦点回到嵌入表里的那一行；第一层还开着。
7. 再按 Enter 打开第二层，这次 Tab 到「返回 SO-1003」按 Enter：同样只关第二层、焦点回到那一行。
8. Esc 关第一层。

**失败**：一次 Esc 关掉两层；听不出进了第二层（「返回」按钮没有外层的订单号，或名字是英文「Close」）；关掉后焦点落在页面开头。

### 任务 5　分析：在托盘里搭一个问题（2 分钟）

[分析工作台 · 订单与商品](https://wow.ahoo.me/storybook/iframe.html?viewMode=story&id=view-engine-业务场景-分析工作台--order-analysis)（`view-engine-业务场景-分析工作台--order-analysis`）

1. 在「视图」列表里按「新建视图」；如果弹出菜单，选「分析视图」。托盘展开、焦点进托盘。
2. 托盘是名为「分析」的区域，里面四个有名字的区域：「范围」「维度」「指标」「结果」（VO+U → 地标可以看到）。
3. 在「维度」里按「添加维度」：一个菜单，↑／↓ 选「渠道」，Enter。**焦点应落在新长出的维度卡上**；卡上的控件都带卡名，如「渠道 的更多设置」「移除维度 渠道」。
4. 在「指标」里按「添加指标」，选一个金额字段（如「实付」），它的「实付 的汇总方式」是一个选择。
5. Tab 到托盘底下的「应用」，Enter。**应听到**「正在查询」，然后「N 组」（没有维度时是「结果已更新」）。
6. 按「移除维度 渠道」：**焦点应落到「添加维度」上**（这个槽里一项都不剩时），不掉到页面开头。

**失败**：加维度或移除之后焦点掉到页面开头；应用后没有「N 组」一类的播报；卡上的按钮只念「更多」而不说是哪张卡。

### 任务 6　分析：切表格与图表，读图（2 分钟）

同一页，在「视图」列表里打开已存的分析「省份 GMV 前 15」（它已经配好了图；刚才新建的那张还没选图型）。刚才那张没保存，会弹出「离开这个视图？」确认框，选「离开」——焦点应在框里、Esc 能取消，顺手记一笔。

1. Tab 到「结果工具栏」，←／→ 走一遍：「结果呈现为」这一组里有「表格」「图表」两颗切换按钮（会念按下与否），然后是「可视化」（同样念按下与否），再是导出。
2. 选「表格」。Tab 进结果表：整张表的行是一个 Tab 站，↑／↓ 走。在某一行上 Enter：**应听到**一个菜单，以这一组命名（如「省份 是 广东」一类），三项「查看这些记录」「按其他维度细分…」「只看这一组」。Esc 关掉，焦点回到那一行。
3. 选「图表」。用 VO+→ 读到图：**应听到**一张图像，名字是「〈图型〉：〈指标〉，按〈维度〉」（如「柱状图：GMV，按省份」一类），停一下后是摘要句，大意是「共 N 组，最高 〈组〉 〈数〉，最低 〈组〉 〈数〉。」（按时间的图是「共 N 期，从 … 到 …，总体上升；最高 …，最低 …。」）
4. VO+Command+T 跳到图旁边的数据表（看不见，只给读屏），它的标题是「〈图的名字〉，数据表」。VO+Shift+↓ 进表，VO+→／VO+↓ 走格子：每行第一格是组名（行标题），数字按图的格式读（百分比轴读作「25%」）。
5. 回工具栏按「可视化」：左侧栏换成图型面板，**焦点落在面板标题上**。Tab 进图型组（单选组，一个 Tab 站，方向键选）：推荐的那张读作「柱状图，推荐」一类，灰掉的读出原因，如「热力图，要两个维度」。面板里的「返回视图列表」收起它。
6. **contrast 再走一次**：[同一页的 contrast 版](https://wow.ahoo.me/storybook/iframe.html?viewMode=story&id=view-engine-业务场景-分析工作台--order-analysis&globals=fvePreset:contrast)，重复第 3、4 步。念的话应与上面相同；眼睛看焦点环和图上的花纹。

**失败**：图只念「图像」没有名字，或没有摘要句；找不到数据表，或表里的数和图上的不一样；表格布局里的行按 Enter 没有追问菜单；进出可视化面板时焦点掉到页面开头。（指标卡的走势小图没有摘要句是已知缺口。）

### 任务 7　仪表盘：在面板之间走，打开面板菜单（2 分钟）

[销售复盘 · 渠道与地域](https://wow.ahoo.me/storybook/iframe.html?viewMode=story&id=view-engine-业务场景-销售复盘--channels)（`view-engine-业务场景-销售复盘--channels`）

1. VO+U → 地标：「仪表盘」（导航，仪表盘列表）、「筛选」（区域，筛选条）。标签页是一组 tab：「概览」「品类」「渠道与地域」「客户」，←／→ 在标签之间走，当前是「渠道与地域」。
2. VO+Command+H 逐个读面板标题：「渠道结构（按月 GMV 占比）」「省份 GMV 前 15」「城市等级 × 渠道」……顺序应与眼睛读的一致（先上后下、行内从左到右）。
3. 用 Tab 走：每块面板有一颗「「〈面板标题〉」的操作」按钮，面板正文是一个以面板标题命名的组（能滚动，所以是 Tab 站），图表面板的正文里是一张有名字的图。
4. 在一颗「……的操作」上 Enter：菜单里「看」这一组有「在工作台中打开」「刷新这个面板」（记录面板还有「导出数据…」）。Esc，焦点回到那颗按钮。
5. 在菜单里按「刷新这个面板」：记下听到了什么（面板刷新目前没有专门的播报）。

**失败**：面板标题读不到或顺序与屏幕不符；两块面板的按钮同名、分不清是哪一块；菜单关掉后焦点不回按钮。

### 任务 8　交叉筛选与嵌入仪表盘的刷新（2 分钟）

还在销售复盘 · 渠道与地域：

1. 「渠道结构（按月 GMV 占比）」的面板头上有一颗「点击筛选「渠道」」按钮。聚焦它，**应听到**这颗按钮和描述「点这个面板的一组，就用它设置仪表盘的「渠道」；再点一次清除。」按下去什么也不做（它是说明；图上的标记只有指针点得到）。
2. 键盘的等价路是筛选条：VO+U → 地标 →「筛选」，Tab 到「渠道」那一组，选一个渠道。**按现在的代码板子什么也不念**（已知缺口 4.1.3），各面板重新加载。记下实际听到的话。
3. 按筛选条上的「清空」：焦点应落到第一个筛选的值上。

再开[嵌入仪表盘 · 带刷新与更新时刻](https://wow.ahoo.me/storybook/iframe.html?viewMode=story&id=view-engine-组件状态-embeddeddashboard--with-refresh)（`view-engine-组件状态-embeddeddashboard--with-refresh`）：

4. 页标题是「订单概览」。嵌入板首行右侧读到「更新于 〈时刻〉」（不是今天时带日期），旁边是「数据新鲜度」一组里的「刷新」按钮。
5. 按「刷新」：面板重新读，按钮在读的时候转圈（转圈的名字是「加载中」）并暂时不可按，读完焦点仍在「刷新」上。这个故事的时钟钉在固定时刻，所以「更新于」后的时间**不会变**；要看时间真的往前走，用第 10 个任务的补偿控制台概览页。

**失败**：交叉筛选的说明按钮读不出描述；筛选条的控件没有名字；「更新于」读不到；按「刷新」后焦点掉到页面开头。

### 任务 9　错误：被拒绝的条件、没有权限（2 分钟）

[服务端拒绝的条件](https://wow.ahoo.me/storybook/iframe.html?viewMode=story&id=view-engine-组件状态-筛选编辑器--rejected-condition)（`view-engine-组件状态-筛选编辑器--rejected-condition`）

1. 页面载入：查询条是 `role=alert`，**应打断**正在念的话，大意是「「仓库」在这份数据上不能这样用：……」，冒号后是服务端的英文原话；后面有「重试」。
2. 展开「筛选」。条件组「仓库 条件」里，**「仓库 操作符」应带「无效数据」**（被拒的是比较方式，所以标在操作符上），「仓库 值」不带。
3. 把「仓库 操作符」改成别的（如「属于」）或按「移除 仓库」，再「应用」：错误消失，**应听到**「正在查询」「共 N 条记录」。

没有权限，两处各看一眼：

4. [首页 · 没有权限](https://wow.ahoo.me/storybook/iframe.html?viewMode=story&id=view-engine-首页--no-permission)（`view-engine-首页--no-permission`）：嵌入的板打不开，**应听到**一条警示，「无法打开这个仪表盘」，大意是「你不能打开这个仪表盘。」
5. [记录详情 · 没有权限](https://wow.ahoo.me/storybook/iframe.html?viewMode=story&id=view-engine-组件状态-记录工作台-记录详情--linked-forbidden)（`view-engine-组件状态-记录工作台-记录详情--linked-forbidden`）：抽屉以 SO-1002 打开，**应听到**「你没有权限查看这条记录。」，没有「重试」（再试也是被拒）。

**失败**：错误出现时什么也不念；条件上没有「无效数据」，无从知道是哪一条；无权限时只有空白或一直在「加载中」。

### 任务 10　补偿控制台的执行抽屉（2 分钟）

**有补偿服务时（推荐，这是真实的宿主）**：服务端按文档站「补偿参考案例」的本地启动一节起来，或用你能连上的测试环境；然后在仓库根目录：

```shell
pnpm --filter wow-compensation-dashboard^... build
VITE_API_BASE_URL=http://127.0.0.1:18083/ pnpm --dir compensation/dashboard dev --host 127.0.0.1
```

打开「失败执行」（`/executions`），Tab 到一行按 Enter，或直接开 `/executions?id=<一条执行的 ID>`。

1. **应听到**对话框，标题是执行的 ID，说明「记录详情」；头部是这一行的「准备」与「〈ID〉 的操作」。
2. VO+Command+H 读节标题：引擎的字段分组之间插着控制台的节——「变更函数」「堆栈跟踪」「应用重试规格」，最后是「执行历史」。
3. 「堆栈跟踪」里：「复制堆栈跟踪」（按下后**应听到**「堆栈跟踪已复制」）、「自动换行」（切换按钮，念按下与否）、行数「N 行」；没有堆栈时读到「没有堆栈」。
4. 「执行历史」是一张嵌入的表：在一行上 Enter 打开第二层，头部是「返回 〈执行 ID〉」，说明是「执行历史」；Esc 只关第二层，焦点回到那一行（同任务 4）。
5. Esc 关抽屉，焦点回到列表里那一行。概览页（`/`）的「更新于」可以顺便看时刻会不会随刷新往前走。

**没有服务时（退路）**：[记录详情 · 宿主节](https://wow.ahoo.me/storybook/iframe.html?viewMode=story&id=view-engine-组件状态-记录工作台-记录详情--host-sections)（`view-engine-组件状态-记录工作台-记录详情--host-sections`）是照补偿控制台的形状搭的：「处理」（宿主的表单）在最前、「同仓订单」（嵌入的表）在字段之后。按上面第 1、2、5 步走，表单与堆栈的第 3 步跳过，并在备注里写明「用的是退路故事」。

**失败**：宿主的节没有标题、读屏的标题列表里找不到；表单控件没有名字；复制后没有任何播报；抽屉关掉后焦点不回那一行。
