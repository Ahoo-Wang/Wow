## 就绪审计 P1 的处置

- **严格 CSP**：内联 `style=` 走 CSSOM，不触发违规；缺口是两处运行时注入的 `<style>`：引擎打包的 @dnd-kit 拖拽样式（它的 `StyleInjector` 支持 `nonce`），与控制台的 sonner（不支持 nonce）。处置（协调者定）：引擎给宿主一个显式的 `nonce` 入口并转交 dnd-kit；控制台静态引入 sonner 的样式表；CSP 指南写清宿主要做什么；CI 用带严格 CSP 响应头的控制台 preview 跑 e2e 作为门。见 R3-P1-3、R3-P1-4。
- **Firefox／WebKit**：三种浏览器量出的面板几何逐一相同；只有 WebKit 下三块板的 ResizeObserver 噪音（R3-P2-6）。
- **读屏**：自动检查能说的见 [r3.md](r3.md)；朗读顺序与弹层的实际表现留给用户的真人走查（暂停点排队第 6 条）。
