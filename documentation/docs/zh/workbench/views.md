# 保存与管理视图

保存的视图记下你看数据的方式——条件、列、排序、指标、图表、面板——下次打开还是那个样子。它从不保存记录本身、你的勾选或你所在的页。

## 谁能看到视图

| 分组 | 谁能看到 | 谁能修改 |
| --- | --- | --- |
| **我的视图** | 只有你 | 你 |
| **共享视图** | 使用这份数据的所有人 | 应用允许的人 |
| **系统视图** | 所有人 | 由组织统一设置；你可以打开，并另存一份副本 |

## 保存

- **保存**把改动存进打开的视图。新视图第一次保存时，会问标题和**可见范围**：**仅自己**或**所有人**。保存共享视图前会先问一句，因为它会改变所有人看到的视图：**更新给所有人**。
- **另存为**用你看到的样子新建一个视图，原来的视图保持不变。要保留自己版本的系统视图，或者你不能修改的共享视图，就用它。
- **还原**回到保存的版本，会先确认。

## 管理视图

视图列表里的**管理视图**列出这份数据的全部视图：

- **拖动**视图调整顺序；视图只在自己的分组内移动。
- **设为默认**让工作台打开这份数据时先打开这个视图；没有设置时，打开列表里的第一个。
- **改名**与**删除**。删除只移除视图，从不删除它的记录；删除共享视图会让所有人失去它。
- **设为共享**与**设为个人**让视图在**我的视图**与**共享视图**之间移动；显示它的仪表盘仍然照常显示它。被共享仪表盘显示着的视图会保持共享。
- **发布为系统视图**给管理员用，前提是应用允许。

## 别人先保存了时

如果你打开视图之后，别人保存了同一个视图，保存时会给出三条出路：**使用最新版本**、**覆盖为我的版本**或**另存为我的副本**。在你选择之前，你的改动都会保留。

如果保存已经发出却没有得到应答——网络断了、服务端没有回复——工作台会说明结果未知，并提供**重试**（可以放心地按）或**放弃**。
