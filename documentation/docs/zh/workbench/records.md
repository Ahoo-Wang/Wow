# 记录视图

记录视图列出记录，一行一条。由你决定看哪些记录、按什么顺序、显示哪些列、怎样排布。

## 筛选

标题栏的**筛选**展开条件。已保存的视图打开时条件是折起的，新视图是展开的；按钮上的小点表示有尚未应用的改动。

- **简单**模式一个字段一个条件：选字段，再选操作符和值。每个字段只提供对它有意义的操作符——日期提供"最近 7 天"这样的范围，状态提供"属于其中任一"。
- **高级**模式把条件放进分组组合：**同时满足**、**满足任一**或**都不满足**，可以按需要层层嵌套（**添加分组**）。
- 改动要按**确定**才生效；编辑区会数出**尚未应用**的项数。**清空**移除全部条件。

结果上方的条件行始终说明结果按什么筛选。从另一个视图打开的视图会多一行**返回 …**，说明它从哪里来。

## 读结果

- **布局**在**表格**、**卡片**之间切换；视图有阶段时还有**看板视图**（每个阶段一栏）。
- **列设置**选择显示哪些列以及它们的顺序。拖动表头的右边缘可以加宽一列。
- **排序**：点列的表头，依次是升序、降序、再回到原样。按住 Shift 可以按多列排序。
- 表格下方的**汇总**给一列求和、平均、最小、最大或计数，分别针对**本页**和符合条件的**全部**行。
- **分页**逐页浏览结果。
- 结果为空时会说明原因：没有记录符合条件，或者还没有任何记录，并提供修改或清空条件。

## 打开一条记录

点一行的空白处——不是它的复选框、链接或操作——在侧边打开它的**记录详情**：这条记录的全部字段，按分组列出，包括长文本和列表里没显示的字段。用键盘时，用方向键在行间移动，按 Enter 或空格打开。你的应用可能在这里加上它自己的内容。

## 勾选与操作

勾选行即可选中；按住 Shift 点击可以连选一段。**操作**列出应用允许你对选中记录做的事——例如重试失败的任务。会改动数据的操作可能先请你确认或填写表单，并逐条说明执行结果。

## 导出

**导出**把结果写成 CSV 文件：**选中**的行，或当前条件下的**全部**行，并注明条件。像电子表格公式那样开头（`=`、`+`、`-`、`@`）的单元格会被写成电子表格不会执行的形式。
