# 仪表盘

仪表盘把多个保存的视图、分析、标题、文字、图片和链接放在一页上，一起筛选。

## 阅读仪表盘

- **标签页**把一块大仪表盘分成几页；工作台会记住你上次看的标签页。
- 顶部的**筛选**一次收窄所有面板——日期范围、分类、搜索。仪表盘还可能有作者设置的**固定范围**。
- **点击图表**做的事由仪表盘作者决定：打开追问菜单、把某个仪表盘筛选设为点中的那一组，或者带着点中的值去另一个视图、仪表盘或页面。
- **刷新**重新读取每个面板。失败的面板保留上一次的结果并提供重试，其他面板照常。
- 记录面板显示总数，并可以翻页。

## 搭一块仪表盘

**新建仪表盘**新建一块；**编辑**让已有的仪表盘进入编辑状态。

- **添加**一个数据面板——**已保存的视图…**或当场搭的**新建分析…**——或一个内容面板：**标题**、**文字…**、**图片…**或**链接…**。
- **摆放**面板：拖动面板标题开头的把手移动它，拖动角落调整大小。用键盘时，在把手上按 Enter，再用方向键。
- **标签页**：**添加标签页**，给标签页改名、调整顺序或删除；面板的菜单可以把它移到另一个标签页。
- **面板菜单**里有**编辑面板**、**复制**、**从仪表盘移除**，以及**点击时…**，用来选择点这个面板时做什么。
- **添加筛选**在筛选条上加一个仪表盘筛选，并说明它作用到哪些面板。

仪表盘的保存与其他视图一样（[保存与管理视图](./views)）。共享的仪表盘只能显示共享视图和系统视图，这样每个打开它的人都能读到每个面板。
