# 分析视图

分析视图回答"上个月按仓库看的订单数与营收"这样的问题。它一组读一行，以表格或图表呈现。

## 提出问题

标题栏的**分析**展开问题。已保存的视图打开时问题是折起的，新视图是展开的。问题分五部分，按彼此的依赖排列：

| 部分 | 设置什么 |
| --- | --- |
| **展开** | 数每条记录里的条目而不是记录本身，例如每个订单的明细行 |
| **指标** | 计量什么：计数、求和、平均、最小或最大、百分位、去重计数。**公式**把两个字段组合起来（金额 − 成本），**派生指标**把指标组合起来（营收 ÷ 订单数），**两个时刻之差**度量一段时长 |
| **维度** | 怎样分组：按字段的取值，按日期（按年、季、月、周、日、小时……），或按周期（星期几、几点、几号、几月） |
| **结果** | 保留哪些组（只保留某个指标满足条件的组）、怎样排序、显示前几组 |
| **范围** | 哪些记录参与——和记录视图的筛选条件一样 |

如果一处改动会让问题缺了必需的东西——删掉最后一个指标、收起某个指标用到的展开——会说明它一并去掉了什么，并提供**撤销**。除非你关掉，问题一改，结果就跟着更新。

## 呈现结果

结果一开始是表格。结果工具栏上的**可视化**在侧边打开图表类型——柱图、折线、面积、组合、饼图、热力图、散点、漏斗、单个数字、瀑布、矩形树图等。能画出这个结果的类型排在前面，其余的是灰色，并写明缺什么。选中的类型有它自己的选项。

分组比视图显示的多时，会写明"显示了 N 组"。缩小范围或少保留几组，才能看到其余的。

## 追问一组

点一根柱、一块扇形或一行，打开它的追问菜单：

- **查看这些记录**打开这一组背后的记录；
- **按其他维度细分…**再按另一个维度拆开它；
- **只显示这一组**把分析收窄到它。

在时间轴上，同一个菜单作用于点中的那段时间。这样打开的视图会多一行**返回 …**。

## 导出

**导出数据…**把各组写成 CSV 文件；图表也可以导出为图片（**导出图片（PNG）**或 SVG）。
