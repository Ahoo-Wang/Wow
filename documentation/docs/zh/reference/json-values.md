# JSON 中的值

Wow 的 JSON（`WowJson`）写出并读取服务的状态、命令和事件：在事件存储中、在快照中、在 Kafka 上和经由 HTTP。本页列出它写成标量的每个平台值类。每一行给出 Manifest 的 schema 为这个类给出的 JSON 类型和格式，它为普通值和边界值写出的文本，以及除此文本之外它还读取什么、拒绝什么。不是 Wow 的客户端（比如 TypeScript 客户端）写出第三列所示的文本，也读到第三列所示的文本。

- 这些类是 JVM 的类：Kotlin 的 `Int` 是 `int`，可空或作为类型实参时是 `Integer`；`ByteArray` 是 `byte[]`。一行只匹配它的类本身，不匹配子类。
- 枚举按名字写出，与其 schema 的 `enum` 列出的一样：`Month` 写作 `"JANUARY"`。
- 属性若持有另一个写成标量的平台类（`Charset`、`Path`、`AtomicLong`），构建会停下，除非声明了它的 schema（[Manifest](../guide/manifest#a-type-written-by-a-custom-serializer)）。
- 本表与 Manifest 所描述的类不一致时，有一个测试会失败。

| 类 | JSON | 写出 | 另外读取的，以及拒绝的 |
| --- | --- | --- | --- |
| `boolean`、`Boolean` | `boolean` | `true`、`false` | 读取 `1` 和 `"true"`。对 `boolean` 拒绝 `null`。 |
| `int`、`Integer` | `integer`、`int32` | `1`、`2147483647`、`-2147483648` | 把 `1.5` 读作 `1`（截断），`1e2` 读作 `100`，`"7"` 读作 `7`。拒绝超出范围的数，`2147483648`。 |
| `short`、`Short` | `integer`、`int32` | `1`，`-32768` 到 `32767` | 与 `int` 相同。拒绝 `40000`。 |
| `byte`、`Byte` | `integer`、`int32` | `1`，`-128` 到 `127` | 读取至多 `255`，把 `200` 回绕为 `-56`。拒绝 `256` 和 `-129`。 |
| `Year` | `integer`、`int32` | `2026`、`0`、`-1`、`12026` | 读取 `"2026"`。拒绝超出 ±999,999,999 的年份。 |
| `long`、`Long` | `integer`、`int64` | `1`、`9223372036854775807` | 与 `int` 相同。拒绝 `9223372036854775808`。JavaScript 的 `number` 只能精确持有至多 2^53 − 1（`9007199254740991`）的整数：更大的请读作 `bigint`。 |
| `BigInteger` | `integer`、`bigint` | `123456789012345678901234567890`，任意长度 | 把 `1.5` 读作 `1`，`1e3` 读作 `1000`，`"12"` 读作 `12`。 |
| `float`、`Float` | `number`、`float` | `1.5`、`0.1`、`3.4028235E38`、`-0.0`；非数和无穷写作字符串 `"NaN"`、`"Infinity"`、`"-Infinity"` | 读取这三个字符串。把 `1e39` 读作 `Infinity`。 |
| `double`、`Double` | `number` | `0.1`、`1.0`、`1.0E300`、`-0.0`；`"NaN"`、`"Infinity"`、`"-Infinity"` 与 `float` 相同 | 读取这三个字符串和 `"1.5"`。把 `1e400` 读作 `Infinity`。 |
| `BigDecimal` | `number`、`decimal` | 它的数字与标度：`2.50` 保留末尾的零，`0.000001`；负标度或很小的值写成指数形式，`1E+3`、`1E-7` | 读取 `"2.50"`。精确读取 `1e400`，不会溢出。 |
| `Instant` | `string`、`date-time` | `"2026-01-02T03:04:05Z"`，总是 UTC；小数部分按需写到纳秒，`"2026-01-02T03:04:05.123456789Z"`；9999 之后的年份带符号，`"+12026-01-01T00:00:00Z"`，1 之前的写作 `"-0001-01-01T00:00:00Z"` | 读取偏移，换算到 UTC（`"2026-01-02T03:04:05+08:00"` 即 `"2026-01-01T19:04:05Z"`），也读取小写的 `t` 和 `z`。把数字读作纪元秒，小数部分为纳秒（`1767323045.5`）。拒绝没有偏移的时间和只有日期的文本。 |
| `OffsetDateTime` | `string`、`date-time` | `"2026-01-02T03:04:05+08:00"`，保留偏移 | 读回为 UTC，`"2026-01-01T19:04:05Z"`：同一瞬间，偏移丢失。把数字读作纪元秒。拒绝没有偏移的时间。 |
| `ZonedDateTime` | `string`、`date-time` | `"2026-01-02T03:04:05+08:00"`：写出偏移，不写时区 | 读回为 UTC，时区丢失。方括号中的时区 `"2026-01-02T03:04:05+08:00[Asia/Shanghai]"` 也读作 UTC。 |
| `Date` | `string`、`date-time` | `"2026-01-02T03:04:05.123Z"`，UTC，总是写出毫秒 | 读取偏移、只有日期的文本（UTC 午夜），并把数字读作纪元毫秒。拒绝其他文本。 |
| `Calendar` | `string`、`date-time` | 与 `Date` 相同，为 UTC：不写出它的时区 | 读回为 UTC。 |
| `LocalDate` | `string`、`date` | `"2026-01-02"`；9999 之后的年份带符号，`"+12026-01-01"`；负年份 `"-0001-01-01"` | 读取日期时间（丢弃时间部分）、`[2026,1,2]`，并把数字读作纪元日。拒绝不带符号的 9999 之后的年份（`"12026-01-01"`）、`"2026-1-2"` 和不存在的日期 `"2026-02-30"`。 |
| `LocalTime` | `string`、`time` | `"03:04:05"`，总是写出秒；小数部分按需，`"03:04:05.12"` | 拒绝 `"3:04"` 和偏移。 |
| `OffsetTime` | `string`、`time` | `"03:04:05+08:00"`；秒为零时省略，`"03:04Z"` | 拒绝没有偏移的时间。 |
| `Duration` | `string`、`duration` | ISO-8601：`"PT1H30M"`、`"PT0S"`；天写作小时，`"PT48H"`；负值 `"PT-1.5S"`；精确到纳秒，`"PT0.000000001S"` | 读取天（`"P1D"` 读作 `"PT24H"`）、小写，并把数字读作秒（`5400.5`）。拒绝月和年（`"P1M"`）以及任何其他文本（`"90m"`）。 |
| `Period` | `string`、`duration` | ISO-8601：`"P1Y2M3D"`、`"P0D"`；周写作天，`"P14D"`；负值 `"P-1M"` | 读取周，`"P2W"`。拒绝时间部分（`"PT1H"`）和数字。 |
| `kotlin.time.Duration` | `string`、`duration` | 与 `Duration` 相同：`"PT1H30M"`，负值 `"PT-1H-30M"`；`INFINITE` 写作 `"PT2562047788015215H30M7S"` | 读取天。把这段文本或更长的读作 `INFINITE`。拒绝 Kotlin 自己的形式（`"1h 30m"`）、月和数字。 |
| `UUID` | `string`、`uuid` | 小写，36 个字符：`"00000000-0000-0001-0000-000000000002"` | 读取大写。拒绝任何其他形式。 |
| `URI` | `string`、`uri` | 原样，已编码：`"https://example.com/a%20b"`、`"urn:isbn:123"`、`"/relative"` | 把 `""` 读作空 URI。拒绝非法字符，`"a b"`。 |
| `URL` | `string`、`uri` | `"https://example.com/a"` | 把 `""` 读作 `null`。拒绝没有协议的文本，`"example.com"`。 |
| `byte[]` | `string`、`byte` | 带填充的 Base64：`"AQID"`、`"//79/A=="`；空数组写作 `""` | 读取数字数组 `[1,2,3]`。拒绝缺少填充（`"AQI"`）和 URL 安全字母表（`-`、`_`）。 |
| `String` | `string` | 原样，按 JSON 的方式转义，`"\u0000"` | 把数字或布尔值读作其文本，`1` 读作 `"1"`。拒绝对象。 |
| `char`、`Character` | `string` | 一个字符，`"c"` | 把数字读作其编码（`65` 读作 `"A"`），把 `""` 读作 `null`。拒绝多于一个字符。 |
| `LocalDateTime` | `string` | `"2026-01-02T03:04:05"`，总是写出秒；9999 之后的年份带符号，`"+12026-01-01T00:00:00"` | 读取末尾的 `Z` 并丢弃它。拒绝偏移（`"+08:00"`）和用空格代替 `T`。 |
| `YearMonth` | `string` | `"2026-01"`、`"0005-01"`；9999 之后的年份不带加号，`"12026-01"`；负年份 `"-0001-01"` | 读取位数较少的年份 `"5-01"` 和 `[2026,1]`。拒绝加号（`"+12026-01"`）、`"2026-1"` 和 13 月。 |
| `MonthDay` | `string` | `"--01-02"`、`"--02-29"` | 拒绝 `"01-02"` 和不存在的日期 `"--02-30"`。 |
| `ZoneId` | `string` | `"Asia/Shanghai"`、`"UTC"`、`"Z"`、`"GMT+08:00"` | 读取偏移 `"+08:00"`。拒绝未知地区和大小写不同的地区，`"asia/shanghai"`。 |
| `ZoneOffset` | `string` | `"+08:00"`、`"+05:30"`、`"-18:00"`；零写作 `"Z"`；秒按需，`"+01:02:03"` | 读取 `"+8"`，并把 `"+00:00"` 读作 `"Z"`。拒绝超出 ±18:00 的偏移（`"+18:30"`）和地区 `"UTC"`。 |
| `TimeZone` | `string` | 它的 ID：`"UTC"`、`"Asia/Shanghai"`、`"GMT+08:00"` | 什么都不拒绝：未知 ID 或单独的偏移（`"+08:00"`）读作 `GMT`。 |
| `Locale` | `string` | BCP 47 标签：`"zh-CN"`、`"zh-Hans-CN"`、`"en-US-POSIX"`；根语言环境写作 `""` | 什么都不拒绝：把 `"zh_CN"` 读作 `"zh-CN"`，也读取任何其他文本；不是标签的文本写回为 `"und"`。 |
| `Currency` | `string` | ISO 4217 代码，`"CNY"` | 把 `""` 读作 `null`。拒绝未知代码和小写代码 `"cny"`。 |
