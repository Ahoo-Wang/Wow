# 开发指南

这些页面每页说明怎样做一件事，代码取自仓库里的示例。它们以[概念](../concepts/)里的思想为前提；每一页都链接到它所依据的概念。

## 领域建模 {#model-the-domain}

| 页面 | 说明怎样 |
| --- | --- |
| [编写聚合](./aggregates) | 编写命令、命令函数和状态；使用服务；创建聚合；向内核要结果、键和定时 |
| [拒绝与错误码](./rejections) | 用声明的错误码拒绝命令，并以调用方、对端、Saga 或测试的身份读取它 |
| [演进事件](./event-evolution) | 用修订号和升级函数改变事件；重命名和退役事件；改变状态的结构 |
| [所有者、空间与标签](./ownership) | 决定聚合归谁所有、核对调用方、转移所有者、给聚合打标签 |
| [唯一键](./unique-keys) | 让一个值在聚合之间保持唯一 |

## 流程 {#processes}

| 页面 | 说明怎样 |
| --- | --- |
| [编写 Saga](./sagas) | 从事件派生命令；处理它们的成功和拒绝；调用另一个上下文 |
| [投影与反应器](./projections) | 写出读模型；对外部世界采取行动；让两者都保持幂等 |
| [定时命令](./scheduling) | 从决定或 Saga 中定时一条命令；运行周期性任务 |
| [失败与重试](./failures) | 给处理函数它自己的重试预算；为失败分类；恢复停放的聚合 |

## 读侧 {#the-read-side}

| 页面 | 说明怎样 |
| --- | --- |
| [读取状态](./reading-state) | 读取聚合在任意版本或时刻的状态、缓存它、写后即可查 |
| [查询快照](./queries) | 按状态查找聚合，用 Kotlin 或经 HTTP；声明索引和脱敏 |
| [查询事件流](./event-queries) | 查询日志，每次提交一行；分析事件 |
| [从服务发布数据集](./datasets) | 基于数仓声明数据集，限定范围并脱敏，然后查询它 |
