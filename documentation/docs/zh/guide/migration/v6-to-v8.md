# Wow v6 迁移到 v8

本站只记录通往当前主版本的直接路径。v6 → v8 指南属于 v8 版本线，按最后发布时的样子保存在 [v8.16.3 发布标签](https://github.com/Ahoo-Wang/Wow/blob/v8.16.3/documentation/docs/zh/guide/migration/v6-to-v8.md)中，包括升级步骤、破坏性变更检查、存储变化与验证清单。

1. 按那份指南从固定的 v6 标签升级到 v8.16.3，并在那里逐项验证门禁。
2. 然后继续[从 8.16 升级到 9.0.0](../migration.md#从-8-16-升级到-9-0-0)以及之后的各个 9.x 章节。

[迁移指南](../migration.md)说明怎样选择路径，以及所有路径共同的完成门禁。
