# 工作台

许多基于 Wow 的应用通过**工作台**展示数据：一边是保存的视图列表，另一边是打开的视图。本页写给使用它的人，例如运营、分析和客服，而不是搭建它的开发者。这里的一切都不需要写代码。

你能做什么取决于应用怎样配置它：它提供哪些数据、哪些字段能筛选或求和、谁能共享视图。下文的名称是工作台自带的措辞；你的应用可能用不同的说法。

## 屏幕 {#the-screen}

- **视图列表**把视图分成**我的视图**、**共享视图**和**系统视图**。**新建视图**新建一个。你可以收起列表，把整个宽度留给视图，或者让视图铺满屏幕。
- **标题栏**写着打开的视图叫什么、是否已保存：**尚未保存**、改动之后的**已修改**，或者**只改了展示**。**保存**紧挨着名字；**更多视图操作**里有**另存为**、**设为共享**或**设为个人**、**放进仪表盘…**和**复制链接**。
- **条件行**说明现在显示的是什么；数据可以搜索时还有一个搜索框。在输入框以外按 **/** 可以跳到它。
- **刷新**重新读取数据；它的箭头设置**自动刷新**。

视图有三种。

## 记录视图：哪些记录 {#record-views-which-records}

记录视图列出记录，每条一行。

**筛选。** **筛选**打开条件。**简单**模式下每个字段一个条件：字段提供适合它的操作符，例如日期的“最近 7 天”、状态的“是其中任一”。**高级**模式把条件组合成组，**同时满足**、**满足任一**或**都不满足**，可以按需要层层嵌套。改动要按**确定**才生效；**清空**移除全部条件。

**阅读结果。**

- **布局**在**表格**、**卡片**之间切换；记录要依次经过几个阶段时，还有**看板视图**，每个阶段一栏。
- **列设置**选择要显示的列及其顺序；拖动表头的边缘可以加宽一列。
- 点按列标题排序；按住 Shift 可以按多列排序。
- 表格下方的汇总显示合计、平均值、最小值、最大值或计数，分别针对当前页和全部符合条件的行。
- 结果为空时会说明原因，并提供修改或清空条件。

**打开一条记录。** 点按一行的空白处，在侧边打开它的详情：每个字段，分组展示，包括列表里没显示的。用键盘时，用方向键移动，按 Enter。在详情里，**K** 和 **J** 移到上一条或下一条记录。

**对记录执行操作。** 选中几行，或按住 Shift 点击选中一段，**操作**会列出应用允许你对它们做的事。修改数据的操作可能要求你确认或填一份表单，并说明每条记录的执行情况。结果未知（因为没有收到回答）的记录会被取消选中：再试之前先刷新查看。

**导出。** **导出**把选中的行，或全部符合条件的行，写成一个 CSV 文件，并注明筛选条件。看起来像电子表格公式开头的单元格会被处理，免得电子表格执行它们。

## 分析视图：多少、多大、按什么分 {#analysis-views-how-many-how-much-by-what}

分析视图回答诸如“上个月各仓库的订单数和收入”这样的问题，每个分组一行，以表格或图表呈现。

**提出问题。** **分析**分几部分打开问题：

| 部分 | 你设置什么 |
| --- | --- |
| **展开** | 统计每条记录内部的条目，而不是记录本身，例如每个订单的明细行 |
| **指标** | 度量什么：计数、求和、平均值、最小值或最大值、百分位数、去重计数；由两个字段组成的**公式**、由两个指标组成的**派生指标**，或**两个时刻之差** |
| **维度** | 怎样分组：按字段的值、按日期（年、季度、月、周、日、小时），或按周期（星期几、一天中的小时） |
| **结果** | 保留哪些分组、按什么顺序、保留多少个 |
| **范围** | 哪些记录参与：与记录视图相同的条件 |

会让问题变得不完整的改动，会说明它去掉了什么，并提供**撤销**。除非你关闭它，结果会随着编辑更新。

**展示结果。** **可视化**打开图表类型：柱状图、折线图、面积图、饼图、热力图、散点图、漏斗图、单个数字、瀑布图、矩形树图等。能画出这个结果的排在前面；其余的说明它们缺少什么。分组多于显示的数量时，视图会说明。

**继续追问。** 点按一根柱子、一个扇区或一行：**查看这些记录**打开它背后的记录；**按其他维度细分…**把它进一步拆开；**只显示这一组**收窄这次分析。以这种方式打开的视图有一行“返回 …”。

**导出。** **导出数据…**把分组写成 CSV；图表还可以导出为 PNG 或 SVG。

## 仪表盘：一页上的几个视图 {#boards-several-views-on-one-page}

仪表盘把保存的视图、分析、标题、文本、图片和链接放在一页上，一起筛选。

**阅读仪表盘。** **标签页**把大的仪表盘分成几页。顶部的**筛选**一次收窄每个面板；仪表盘还可能有一个作者设定的固定范围。点按图表会执行作者选择的动作：打开后续操作菜单、设置一个仪表盘筛选，或者转到另一个视图。失败的面板保留它上一次的结果，并提供重试。

**搭建仪表盘。** **新建仪表盘**新建一个；**编辑**打开已有的仪表盘进行编辑。**添加**一个数据面板（一个保存的视图，或当场新建的分析）或一个内容面板（标题、文本、图片或链接）。拖动面板的拖动柄移动它，拖动角落调整大小；用键盘时，在拖动柄上按 Enter，再用方向键。面板的菜单可以编辑、复制或移除它，把它移到另一个标签页，以及选择点按它时做什么。**添加筛选**把一个仪表盘筛选放到筛选栏上，并说明它作用于哪些面板。

共享的仪表盘只能展示共享视图和系统视图，这样每个打开它的人都能读到每个面板。

## 保存和共享视图 {#save-and-share-views}

保存的视图记下的是你观察数据的方式：条件、列、排序、指标、图表、面板。它从不保存记录本身、你的选中项或你所在的页码。

| 分组 | 谁能看到 | 谁能修改 |
| --- | --- | --- |
| **我的视图** | 只有你 | 你 |
| **共享视图** | 每个使用这份数据的人 | 应用允许的人 |
| **系统视图** | 所有人 | 你的组织；你可以打开它们并另存一份 |

- **保存**把你的改动保存到打开的视图里。第一次保存时会要求填写标题和**可见范围**：**仅自己**或**所有人**。保存共享视图之前会先询问，因为它会为所有人改变这个视图。
- **另存为**用你看到的样子新建一个视图，原视图保持不变。这是保留你自己版本的系统视图的方式。
- **还原**回到已保存的版本。**⌘S**（Ctrl+S）保存。
- 带着未保存的改动离开视图时，会先询问。

**管理视图**列出这份数据的每个视图：拖动以调整顺序；**设为默认**选择默认打开的视图；**改名**、**删除**；**设为共享**或**设为个人**，视图在任何展示它的仪表盘上的位置都会保留。管理员还可以**发布为系统视图**。

**别人先保存了时**，保存会提供**使用最新版本**、**覆盖为我的版本**或**另存为我的副本**；在你选择之前，你的改动都会保留。**保存没有收到回答时**，工作台会说明结果未知，并提供**重试**（这是安全的，因为同一个请求不会生效两次）或**放弃**（你的改动留在屏幕上，未保存）。

## 出了问题时 {#when-something-goes-wrong}

- 查询失败时，在原本显示结果的地方说明，并提供重试的方式；上一次的结果仍留在屏幕上。
- 无法按保存时的样子运行的视图，例如它用到的字段不在了，或某个条件不再允许，会说明需要修正什么，并提供移除不可用的部分。
