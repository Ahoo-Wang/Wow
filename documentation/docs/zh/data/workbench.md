# 使用工作台

许多基于 Wow 的业务应用通过**工作台**展示数据：左边是保存的视图列表，右边是打开的视图。这几页写给使用它的人——运营、分析、客服——而不是搭建它的研发。这里的一切都不需要写代码。

能做什么取决于应用怎样配置：它提供哪些数据、哪些字段能筛选或求和、谁能共享视图。下文用的是工作台的默认措辞，你的应用可能用它自己的说法。

## 三种视图

| 种类 | 回答 | 读 |
| --- | --- | --- |
| **记录视图** | 哪些记录符合条件，一行一条：筛选、排序、选列、打开一条记录、导出 | [记录视图](./workbench.md) |
| **分析视图** | 多少、多大、按什么分：按维度看指标，以表格或图表呈现 | [分析视图](./workbench.md) |
| **仪表盘** | 把多个视图和图表放在一页上，一起筛选 | [仪表盘](./workbench.md) |

每个视图都可以保存、共享，并设为默认打开的那一个：[保存与管理视图](./workbench.md)。

## 屏幕

- **左边的视图列表**按**我的视图**、**共享视图**、**系统视图**分组。**新建视图**新建一个。**收起视图列表**把整个宽度留给视图，**铺满屏幕**隐藏视图周围的一切。
- **标题栏**写着打开的视图叫什么、存过没有：新视图是**尚未保存**，改动之后是**已修改**，只改了展示时是**只改了展示**。**保存**紧跟在名字旁边，其余的在**更多视图操作**里：**另存为**、**设为共享**或**设为个人**、**放进仪表盘…**（把视图作为一块面板加到你能修改的仪表盘上），以及页面地址里带着视图时的**复制链接**。
- **条件行**说明现在显示的是什么；数据可以搜索时，它的末端有一个搜索框，按 Enter 才执行搜索。在输入框以外的任何位置按 **/** 可以直接跳到搜索框。
- **刷新**重新读取数据。它旁边的箭头设置**自动刷新**，结果上写着最近一次更新的时间。

## 出了问题时

- 查询失败时，在原本显示结果的地方说明，并提供重试；上一次的结果仍留在屏幕上。
- 视图无法按保存时的样子运行——它用到的字段不在了，或者某个条件不再允许——会说明需要修正什么，并提供移除不可用条件。
- 带着未保存的改动离开视图时，工作台会先问一句：**留下**还是**离开**。
