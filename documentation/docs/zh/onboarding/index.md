# 评估与参与

按你需要做出的决策选择入口。

| 读者 | 需要做出的决策 | 第一页 | 完成信号 |
| --- | --- | --- | --- |
| 贡献者 | 我能构建并验证一个可评审的 Wow 变更吗？ | [贡献者指南](./contributor-guide.md) | 本地检查通过，且变更具有清晰的评审边界 |
| Staff Engineer | Wow 是否适合我们的架构和运行模型？ | [Staff Engineer 指南](./staff-engineer-guide.md) | 收益、不变量、依赖、迁移和恢复责任明确 |
| 管理者 | 采用是否由价值、成本和交付风险证明合理？ | [管理者指南](./executive-guide.md) | 决策明确预期价值、责任归属、证据和停止条件 |
| 产品经理 | 领域行为能否成为可测试的验收标准？ | [产品经理指南](./product-manager-guide.md) | 命令、事件、完成语义和失败结果明确 |
