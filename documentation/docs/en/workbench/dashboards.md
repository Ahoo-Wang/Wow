# Dashboards

A dashboard puts several saved views, analyses, headings, text, images and links on one page, filtered together.

## Read a dashboard

- **Tabs** split a large dashboard into pages; the workbench remembers the tab you last looked at.
- **Filters** at the top narrow every panel at once — a date range, a category, a search. A dashboard may also have a **Fixed scope** its author set.
- **Pressing a chart** does what the dashboard's author chose: open the follow-up menu, update a dashboard filter to the group pressed, or go to another view, dashboard or page with the value pressed.
- **Refresh** reads every panel again. A panel that fails keeps its last result and offers to try again; the others go on.
- A record panel shows its total and pages through its rows.

## Build a dashboard

**New dashboard** starts one; **Edit** turns an existing one into its editing mode.

- **Add** a **Data** panel — a **Saved view…** or a **New analysis…** built on the spot — or a **Content** panel: a **Heading**, **Text…**, an **Image…** or **Links…**.
- **Arrange** panels by dragging the handle at the start of a panel's title, and resize them from the corner. With the keyboard, press Enter on the handle and use the arrow keys.
- **Tabs**: **Add a tab**, rename, reorder or delete one; a panel's menu moves it to another tab.
- **A panel's menu** holds **Edit panel**, **Duplicate**, **Remove from dashboard**, and **When clicked…**, which chooses what a press on that panel does.
- **Add filter** puts a dashboard filter on the bar and says which panels it reaches.

Save the dashboard as you save any view ([Saving and managing views](./views)). A shared dashboard can show only shared and system views, so everyone who opens it can read every panel.
