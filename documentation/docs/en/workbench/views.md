# Saving and Managing Views

A saved view keeps the way you look at the data — conditions, columns, sort, metrics, chart, panels — so it opens the same way next time. It never keeps the records themselves, your selection or the page you were on.

## Who sees a view

| Group | Who sees it | Who can change it |
| --- | --- | --- |
| **My views** | Only you | You |
| **Shared views** | Everyone who uses this data | Those your application allows |
| **System views** | Everyone | Set up by your organisation; you can open them and save a copy |

## Save

- **Save** keeps your changes in the open view. The first save of a new view asks for a title and **Who can see it**: **Only me** or **Everyone**. Saving a shared view asks first, because it changes it for everyone: **Update for everyone**.
- **Save as** makes a new view from what you see; the view you started from stays as it was. It is how you keep your own version of a system view or of a shared view you may not change.
- **Revert** goes back to the saved version, after asking.

## Manage views

**Manage views**, in the view list, lists every view of this data:

- **Drag** a view to reorder the list; views move within their own group.
- **Open this one first** makes a view the one the workbench opens for this data; without one, it opens the first in the list.
- **Rename** and **Delete**. Deleting removes only the view, never its records; deleting a shared view removes it for everyone.
- **Make shared** and **Make personal** move a view between **My views** and **Shared views**; it keeps its place on any dashboard that shows it. A view a shared dashboard shows stays shared.
- **Publish as a system view** is there for administrators, when the application allows it.

## When someone else saved first

If someone saved the same view after you opened it, saving offers three ways out: **Take theirs**, **Keep mine** (write yours over theirs) or **Save my copy**. Your changes are kept until you choose.

If a save was sent but no answer came back — the network dropped, the server did not reply — the workbench says the outcome is unknown and offers **Try again**, which is safe to press, or **Abandon**.
