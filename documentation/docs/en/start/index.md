# Start Here

Pick the path that matches what you came to do. Each lists the pages to read in order; the rest of the site is there when you need it.

## Deciding whether to use Wow

1. [Why Wow](./why-wow): what it does, the principles, what it assumes, and when it is not the right tool.
2. [Quickstart](./quickstart): one service from an empty project to a command sent and its state read, in about thirty minutes.
3. [Concepts](../concepts/): the log, the write path, subscriptions, read models and the contract.
4. [Tutorial](./tutorial): two contexts working together, from a basket to an order.

## Building a service in Kotlin or Java

1. [Quickstart](./quickstart), or [Add Wow to an Existing Service](./existing-project).
2. [Guide](../guide/): aggregates and rejections, sagas, projections, reading and querying, calling other services, testing, and the Spring Boot host.
3. [Agent Skills](./skills): the `wow-develop` Skill writes, reviews and diagnoses with you.

## Calling a service from TypeScript
