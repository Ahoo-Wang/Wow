# Migrate Wow v6 to v8

This site documents the direct path to the current major version. The v6 → v8 guide belongs to the v8 line and is kept, as last published, at the [v8.16.3 release tag](https://github.com/Ahoo-Wang/Wow/blob/v8.16.3/documentation/docs/en/guide/migration/v6-to-v8.md), with its upgrade steps, breaking-changes check, storage changes and verification checklist.

1. Follow that guide from your pinned v6 tag to v8.16.3, and verify each gate there.
2. Continue with [Upgrading from 8.16 to 9.0.0](../migration.md#upgrading-from-8-16-to-9-0-0) and the 9.x sections after it.

The [Migration Guide](../migration.md) explains how to choose a path and the completion gates every path shares.
