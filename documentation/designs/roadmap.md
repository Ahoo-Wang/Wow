日期：2026-11-10（初稿 2026-10-11）。状态：持续维护。架构见 [00](00-architecture.md)，决定见[决策台账](decisions.md)，现状见[进度](progress.md)。

本页写里程碑、未完成的工作包，以及已登记、未排期的事项（§6）；不写逐步实施计划。一项完成即从本页删去，明细以 git 历史为准；2026-11-10 压缩前的最后一版为 `2c08f318ea`。

## 1. 分支与发布

| 规则 | 内容 |
| --- | --- |
| `main` | Wow 10 的开发与发布线。改动走 PR、squash 合并；必需检查为 PR Safety 与 `ci-gate`；协调者审查后开启自动合并 |
| `v9` | 9.x 维护线：只修缺陷，自有的工作流与发布准入，不再接受依赖更新（用户 2026-10-25）；Wow 10 GA 后只收安全补丁，为期 12 个月（D19）。文档站的 `/9.x/` 由 `main` 的部署工作流从 `v9` 构建 |
| 预发布 | 最近一次是 `10.0.0-beta.1`（2026-11-02）；下一个是 `10.0.0-beta.2`（用户 2026-11-12，在[进度](progress.md) §2 的两项了结之后）。从 `main` 上的标签 `v<版本>` 由 `package-deploy.yml` 发布：Maven Central、npm 的预发布 dist-tag、镜像、GitHub 预发布；步骤见 `AGENTS.md` 的 Releasing 一节。不做兼容性承诺；GA 前各格式号保持 1，不考虑预发布的数据（D414）。打标签与对外发布须用户确认（D202） |
| rc 与 GA | 从 `main` 发 `10.0.0-rc.n` 与 `10.0.0`，途径同上；rc 须用户确认，GA 打标签前问用户（D124、D202），时间由用户决定 |
| GA 之后 | 10.x 内相邻次版本须能滚动升级（D48）；`mixed-version` 检查在 10.0 GA 后以「上一个 10.x 次版本 + 当前构建」重新启用 |
